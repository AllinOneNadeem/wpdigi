# WPDigi — Gemini AI Site & Store Manager

**All-in-One Gemini AI Suite for WordPress & WooCommerce** (Version 3.0.0)

## Features
- 🤖 WooCommerce Digital & Physical Product Generator (Gemini AI)
- 👀 Live Preview
- 🔍 Full SEO Auditor
- 📊 RankMath 4x2 Grid Modules
- ♻️ 1-Click Restore
- 🔄 GitHub Updater

## Installation
1. Download this repository and upload the plugin to `wp-content/plugins/` (or upload the zip from WordPress Admin → Plugins → Add New → Upload).
2. Activate **Gemini AI Site & Store Manager** from the Plugins menu.
3. Open the plugin settings in WP Admin and configure your Gemini API options.
